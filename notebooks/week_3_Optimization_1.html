10  Moduel 3: The Mathematics of Optimization

Whether you are finding the most stable 3D geometry of a drug molecule, locating a transition state for a chemical reaction, or fitting experimental kinetic data to a rate law, you are doing the exact same mathematical task: Optimization.

In computational chemistry, optimization almost always means finding the minimum of a function (usually the Potential Energy).

10.1 1. Analytical vs. Numerical Optimization

You already know the analytical way to find a minimum from standard calculus: take the derivative of the function, set it to zero (\(f'(x) = 0\)), and solve for \(x\). We can use symbolic math tools like SymPy to do this exactly.

However, analytical solutions are only possible for simple equations (like the Harmonic Oscillator). What if your “function” is the energy of a 50-atom protein folding in water? There is no analytical derivative for that. We have to use Numerical Optimization—algorithmic searching where the computer essentially “feels” its way down the energy landscape.

10.2 2. The Landscape: Local vs. Global Minima

Imagine dropping a marble onto a rugged, hilly landscape. Gravity pulls it downhill until it settles in a valley. But is it the lowest possible valley on the entire map, or just a shallow crater halfway down a mountain?

  • Global Minimum: The lowest energy state of the entire system (e.g., the true ground state of a molecule).
  • Local Minimum: A stable configuration, but not the lowest possible (e.g., a misfolded protein or a stable intermediate).

Because numerical algorithms only look at the local area immediately around them, they will blindly walk down into the nearest valley and stop. A computer algorithm cannot easily tell if it is in a local or global minimum. This is why your initial starting guess is the most important part of any computational chemistry calculation!

10.4 4. How Computers Search: The Nelder-Mead (Downhill Simplex) Method

If you look closely at the code above, you’ll see we told scipy to use method='Nelder-Mead'. How exactly does a computer “walk downhill” without knowing the analytical derivative of the function?

The Nelder-Mead Method (often called the Downhill Simplex) is one of the most intuitive algorithms. A “simplex” is a geometric shape with \(N+1\) corners, where \(N\) is the number of variables you are optimizing. For our 2D landscape above, the simplex is a triangle.

Instead of rolling a single marble, Nelder-Mead drops a flexible triangle onto the landscape. It evaluates the energy at all three corners, finds the highest energy point (the worst one), and then morphs the triangle away from that bad point using four basic moves:

  1. Reflect: Flip the worst point across the center of the other points (moving away from the high energy).
  2. Expand: If the reflection finds a steep downhill slope, stretch the triangle further in that direction.
  3. Contract: If the reflection hits a wall, pull the point closer in.
  4. Shrink: If all else fails, shrink the entire triangle around the best known point.

The Downhill Simplex is incredibly useful in chemistry because it does not require derivatives, making it perfect for messy, noisy experimental data or complex quantum wavefunctions. Notice how the triangle flips (reflects) to walk downhill, stretches (expands) when it finds a steep slope, and shrinks tightly around the center when it hits the bottom!

10.5 5. A Field Guide to Optimization Algorithms

When using scipy.optimize.minimize, you can choose the specific algorithm the computer uses. Here is a cheat sheet for the most common ones you will encounter in computational chemistry:

Algorithm Needs Derivatives? Best Used For Weakness
Nelder-Mead (Simplex) No Noisy data, functions where derivatives are impossible to calculate. Slow for problems with many variables (>10).
Gradient Descent Yes Simple, smooth surfaces. Often zig-zags and converges very slowly near the minimum.
BFGS (Quasi-Newton) Yes The workhorse of quantum chemistry. Geometry optimizations and transition states. Can fail catastrophically if the starting guess is very bad.
Simulated Annealing No Escaping local minima. It intentionally takes “bad” uphill steps based on a simulated temperature. Very computationally expensive.

## 3. Interactive Sandbox: Escaping Local Minima

Let's visualize this. The interactive Python block below defines a rugged Potential Energy Surface. It combines a deep central bowl (the global minimum) with shallow ripples (local minima).

We will run `scipy.optimize.minimize` twice, from two different starting guesses, and plot the path the algorithm takes across the landscape. 

**Your Mission:** Run the code to see the Red path get trapped in a local minimum, while the Green path finds the global minimum. Then, **change the coordinates of `guess_1` in the code** and run it again to see if you can make the Red path find a different local valley!

```{pyodide}
import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import minimize

# 1. Define our "Rugged" Potential Energy Function
# Takes an array of coordinates pos = [x, y]
def rugged_potential(pos):
    x, y = pos[0], pos[1]
    bowl = 0.1 * (x**2 + y**2)
    ripples = -np.cos(2*x) - np.cos(2*y)
    return bowl + ripples + 2.0 

# 2. Tracking the Optimizer's Path
# We use this callback function to save every step the algorithm takes
def make_tracker(path_list):
    def tracker(xk):
        path_list.append(xk.copy())
    return tracker

# --- CHANGE THESE GUESSES AND CLICK RUN ---
guess_1 = [3.5, 3.5]  # The Red starting point (Trapped!)
guess_2 = [1.0, 1.0]  # The Green starting point (Finds the global min)
# ------------------------------------------

# Run Optimization 1
path_1 = [guess_1]
res_1 = minimize(rugged_potential, guess_1, callback=make_tracker(path_1), method='Nelder-Mead')
path_1 = np.array(path_1)

# Run Optimization 2
path_2 = [guess_2]
res_2 = minimize(rugged_potential, guess_2, callback=make_tracker(path_2), method='Nelder-Mead')
path_2 = np.array(path_2)


# 3. Plotting the Results
x_grid = np.linspace(-5, 5, 100)
y_grid = np.linspace(-5, 5, 100)
X, Y = np.meshgrid(x_grid, y_grid)
Z = rugged_potential([X, Y])

fig = plt.figure(figsize=(12, 5))

# Left Plot: 3D Surface
ax1 = fig.add_subplot(121, projection='3d')
ax1.plot_surface(X, Y, Z, cmap='viridis', edgecolor='none', alpha=0.6)
ax1.plot(path_1[:,0], path_1[:,1], rugged_potential([path_1[:,0], path_1[:,1]]), color='red', marker='o', label='Path 1 (Local)')
ax1.plot(path_2[:,0], path_2[:,1], rugged_potential([path_2[:,0], path_2[:,1]]), color='lime', marker='^', label='Path 2 (Global)')
ax1.set_title('3D Energy Landscape')
ax1.legend()

# Right Plot: 2D Contour Map (Top-Down View)
ax2 = fig.add_subplot(122)
contour = ax2.contourf(X, Y, Z, levels=20, cmap='viridis', alpha=0.8)
fig.colorbar(contour, ax=ax2, label='Potential Energy')

# Plot the paths on the contour map
ax2.plot(path_1[:,0], path_1[:,1], color='red', marker='o', linestyle='-', linewidth=2, label='Path 1')
ax2.plot(path_2[:,0], path_2[:,1], color='lime', marker='^', linestyle='-', linewidth=2, label='Path 2')

# Mark the start and end points
ax2.scatter(path_1[0,0], path_1[0,1], color='white', s=100, edgecolors='black', label='Start')
ax2.scatter(path_2[0,0], path_2[0,1], color='white', s=100, edgecolors='black')

ax2.set_xlabel('Parameter X')
ax2.set_ylabel('Parameter Y')
ax2.set_title('Top-Down Contour Map of Optimizer Paths')
ax2.legend()

plt.tight_layout()
plt.show()

print(f"Path 1 stopped at Energy = {res_1.fun:.3f}")
print(f"Path 2 stopped at Energy = {res_2.fun:.3f}")
```

## 4. How Computers Search: The Nelder-Mead (Downhill Simplex) Method

If you look closely at the code above, you'll see we told `scipy` to use `method='Nelder-Mead'`. How exactly does a computer "walk downhill" without knowing the analytical derivative of the function? 

The **Nelder-Mead Method** (often called the Downhill Simplex) is one of the most intuitive algorithms. A "simplex" is a geometric shape with $N+1$ corners, where $N$ is the number of variables you are optimizing. For our 2D landscape above, the simplex is a triangle.

Instead of rolling a single marble, Nelder-Mead drops a flexible triangle onto the landscape. It evaluates the energy at all three corners, finds the *highest* energy point (the worst one), and then morphs the triangle away from that bad point using four basic moves:

1.  **Reflect:** Flip the worst point across the center of the other points (moving away from the high energy).
2.  **Expand:** If the reflection finds a steep downhill slope, stretch the triangle further in that direction.
3.  **Contract:** If the reflection hits a wall, pull the point closer in.
4.  **Shrink:** If all else fails, shrink the entire triangle around the best known point.

The Downhill Simplex is incredibly useful in chemistry because it **does not require derivatives**, making it perfect for messy, noisy experimental data or complex quantum wavefunctions.
Below is an animation of the Nelder-Mead simplex hunting for the minimum of a 2D energy well. Notice how the triangle flips (reflects) to walk downhill, stretches (expands) when it finds a steep slope, and shrinks tightly around the center when it hits the bottom!
```{python}
#| echo: false

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.animation import FuncAnimation
from IPython.display import HTML

# Define a simple 2D well
def f(pos):
    return pos[0]**2 + 2*pos[1]**2

# Custom mini Nelder-Mead generator just to save the triangle states
def get_simplex_path():
    # Start with a large triangle far from the minimum (0,0)
    simplex = np.array([[-4.0, 4.0], [-2.0, 4.5], [-3.0, 2.0]])
    path = [np.copy(simplex)]
    # Testing shows 18 steps finds reasonable minimum
    for _ in range(18):
        # Sort vertices by energy
        order = np.argsort([f(p) for p in simplex])
        simplex = simplex[order]
        best, good, worst = simplex[0], simplex[1], simplex[2]
        centroid = (best + good) / 2.0
        
        # Reflect
        ref = centroid + 1.0 * (centroid - worst)
        if f(best) <= f(ref) < f(good):
            simplex[2] = ref
        elif f(ref) < f(best):
            # Expand
            exp = centroid + 2.0 * (ref - centroid)
            if f(exp) < f(ref): simplex[2] = exp
            else: simplex[2] = ref
        else:
            # Contract
            if f(ref) < f(worst):
                con = centroid + 0.5 * (ref - centroid)
                if f(con) < f(ref): simplex[2] = con
                else:
                    simplex[1] = best + 0.5*(good - best)
                    simplex[2] = best + 0.5*(worst - best)
            else:
                con = centroid + 0.5 * (worst - centroid)
                if f(con) < f(worst): simplex[2] = con
                else:
                    simplex[1] = best + 0.5*(good - best)
                    simplex[2] = best + 0.5*(worst - best)
        path.append(np.copy(simplex))
    return path

path = get_simplex_path()

# Setup the plot
fig, ax = plt.subplots(figsize=(8, 6))
x_grid = np.linspace(-1, 5, 100)
y_grid = np.linspace(-1, 5, 100)
X, Y = np.meshgrid(x_grid, y_grid)
Z = X**2 + 2*Y**2
ax.contourf(X, Y, Z, levels=20, cmap='Blues', alpha=0.6)
ax.plot(0, 0, marker='*', color='gold', markersize=15, markeredgecolor='black', label="Minimum")

# Initialize the triangle patch
triangle, = ax.plot([], [], 'o-', color='crimson', linewidth=2, markersize=8)

def init():
    triangle.set_data([], [])
    return triangle,

def animate(i):
    # To close the triangle, we append the first point to the end
    xs = np.append(path[i][:, 0], path[i][0, 0])
    ys = np.append(path[i][:, 1], path[i][0, 1])
    triangle.set_data(xs, ys)
    ax.set_title(f"Nelder-Mead Search: Step {i}")
    return triangle,

anim = FuncAnimation(fig, animate, init_func=init, frames=len(path), interval=800, blit=True)
plt.close() # Prevent static plot from showing

# Display as an interactive HTML5 video player in the book
HTML(anim.to_jshtml())
```
